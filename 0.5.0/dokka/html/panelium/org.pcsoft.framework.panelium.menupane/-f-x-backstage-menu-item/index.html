FXBackstageMenuItem

class FXBackstageMenuItem(var icon: Node? = null, var text: String = "", var content: Node? = null)

A single entry in an FXBackstageMenuPane's menu list. icon is an optional leading graphic, text the label shown beside it, and content the node displayed in the pane's content area while this item is the selected one.

Instantiable from FXML through the no-arg constructor: <FXBackstageMenuItem text="Info"> with icon and content as property elements.
