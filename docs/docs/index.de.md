# PaneliumFX

Eine JavaFX-UI-Bibliothek mit einem eigenen Fensterrahmen (Platinum Chrome) und einem MenuPane-Steuerelement.

Diese Dokumentation beschreibt, wie die öffentliche API der Bibliothek genutzt wird.
Anweisungen zum Bauen und zur Mitwirkung finden sich in der `README.md` des Projekts.

## Was es ist

`PaneliumFX` stellt einen eigenen, undekorierten Fensterrahmen (Platinum Chrome) für
JavaFX-Anwendungen bereit und, in einer späteren Version, ein MenuPane-Steuerelement,
das Aktionen in Tabs und Gruppen ähnlich den Menüleisten gängiger Office-Anwendungen
zusammenfasst.
